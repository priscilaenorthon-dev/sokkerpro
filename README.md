## 🔄 Combinando os Bots

Você agora tem **3 bots disponíveis**:
1. **Bot 1T COM gol** (Over 0.5 1T) - Minutos 10-35 - Jogos ofensivos
2. **Bot 1T SEM gol** (Under 0.5 1T) - Minutos 10-35 - Jogos travados
3. **Bot 2T COM gol** (Over 0.5 2T) - Minutos 50-80 - Segundo tempo

### ⚠️ REGRAS IMPORTANTES:

1. **No primeiro tempo:** Escolha **APENAS UM** bot (COM gol OU SEM gol, nunca ambos!)
2. **Entre tempos:** Se entrou no 1T, **NÃO** entre no 2T do mesmo jogo
3. **Estratégia:** Analise o jogo e escolha o bot mais adequado para cada situação
